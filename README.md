# Codex Test Repository

This is a small **test repository** for learning how to use Codex safely.

## Project purpose
- Practice asking Codex for small, clear changes.
- Learn how to review changes before accepting them.
- Build safe habits before working in bigger projects.

## Intended use
Use this repository to:
- Try beginner-friendly prompts.
- Request simple documentation edits.
- Learn the basic workflow: ask -> review -> approve.
- Suggested practice prompt: "Ask for a tiny change and review the diff."

## Safety rules
- Start with small, low-risk requests.
- Ask Codex to explain changes in plain English.
- Review file diffs before using changes anywhere else.
- Avoid secrets or private data in prompts or files.
- Prefer documentation updates before code changes.
